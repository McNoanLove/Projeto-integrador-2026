Fundamentação Teórica & Formulação Matemática

Exploração matemática e física exaustiva dos três fenômenos fundamentais que regem o balanço energético da piscina sustentável.

1. Ondas Eletromagnéticas & Espectro Solar

A energia transmitida pelo Sol atravessa o vácuo como uma oscilação acoplada de campos elétricos ($\vec{E}$) e magnéticos ($\vec{B}$), governada pelas Equações de Maxwell. A velocidade de propagação no vácuo é dada por:

$$c = \frac{1}{\sqrt{\mu_0 \varepsilon_0}} \approx 3 \times 10^8 \text{ m/s}$$

A energia quântica transportada por cada fóton atende à relação de Planck-Einstein:

$$E = h \cdot f = \frac{h \cdot c}{\lambda}$$
  • Ultravioleta (UV, 100-400 nm): Detecção via sensor UV para índice de insolação.
  • Luz Visível (400-700 nm): Principal faixa absorvida pelo revestimento negro.
  • Infravermelho (IR, >700 nm): Responsável direto pelo aquecimento radiativo e perdas térmicas.

2. Radiação do Corpo Negro & Lei de Wien

Um corpo negro ideal absorve 100% da radiação incidente ($\alpha = 1$). A potência total irradiada por unidade de área é dada pela Lei de Stefan-Boltzmann:

$$P = \varepsilon \cdot \sigma \cdot A \cdot T^4$$

$(\sigma \approx 5{,}670 \times 10^{-8} \text{ W/m}^2\text{K}^4)$

Pela Lei do Deslocamento de Wien, o comprimento de onda de pico ($\lambda_{máx}$) varia inversamente com a temperatura absoluta:

$$\lambda_{máx} = \frac{b}{T} \quad (b \approx 2{,}897 \times 10^{-3} \text{ m}\cdot\text{K})$$
Justificativa Física da Capa Térmica: O Sol ($T \approx 5800\text{ K}$) emite em $\lambda_{máx} \approx 500\text{ nm}$ (visível). A água da piscina ($T \approx 298\text{ K}$) emite em $\lambda_{máx} \approx 9{,}7\,\mu\text{m}$ (Infravermelho Distante). A capa impede a dissipação dessa radiação e bloqueia a evaporação.

3. Efeito Fotoelétrico & Células Fotovoltaicas

A energia luminosa incide sobre o semicondutor de Silício ($Si$), transferindo energia aos elétrons da banda de valência. A energia cinética máxima do fotoelétron ejetado atende à equação de Einstein:

$$E_{k\_máx} = h \cdot f - \Phi$$

Onde $\Phi$ representa a Função Trabalho do material. Se $h \cdot f < \Phi$, nenhum elétron é liberado.

  • Junção P-N: O campo elétrico interno direciona os elétrons livres gerando corrente contínua ($CC$).
  • Inversor / Driver: Alimenta as bombas elétricas de circulação sem gastar energia da rede concessionária.

Conclusões Tecnocientíficas do Balanço:

1. Deslocamento Espectral: Devido à enorme diferença de temperatura entre o Sol ($5800\text{ K}$) e a água da piscina ($298\text{ K}$), a energia incidente chega predominantemente na faixa da luz visível e UV, enquanto a energia perdida pela piscina ocorre exclusivamente no infravermelho distante.

2. Opacidade da Capa Térmica: O material polimérico de bolhas da capa térmica possui alta transmissividade para a luz visível (deixando a energia entrar durante o dia), mas é extremamente opaco para o infravermelho distante (restringindo a saída de fótons térmicos à noite).

C++ / FreeRTOS / ESP32 
// PROJETO INTEGRADOR CEP - AUTOMAÇÃO DE PISCINA SUSTENTÁVEL
// FIRMWARE EMBARCADO ESP32 (FreeRTOS + 1-Wire + Telemetria)

#include <WiFi.h>
#include <OneWire.h>
#include <DallasTemperature.h>

#define PIN_DS18B20 4       // Pino digital do sensor de temperatura da água
#define PIN_LDR 34          // Pino analógico ADC do sensor de luminosidade LDR
#define RELE_BOMBA 12       // Relé da bomba de recirculação do coletor solar
#define RELE_CAPA_FECHAR 13 // Relé do motor de desdobramento da capa térmica
#define RELE_CAPA_ABRIR 14  // Relé do motor de recolhimento da capa térmica

OneWire oneWire(PIN_DS18B20);
DallasTemperature sensors(&oneWire);

// Tarefa FreeRTOS 1: Leitura de Sensores
void TaskSensorRead(void *pvParameters) {
  for(;;) {
    sensors.requestTemperatures();
    float tempAgua = sensors.getTempCByIndex(0);
    int ldrVal = analogRead(PIN_LDR);

    // Lógica Lógica de Decisão em Tempo Real
    if (ldrVal < 500) { 
      // MODO NOTURNO: Fechar capa para bloquear irradiação IV distante
      digitalWrite(RELE_CAPA_ABRIR, LOW);
      digitalWrite(RELE_CAPA_FECHAR, HIGH);
      digitalWrite(RELE_BOMBA, LOW); // Interrompe bombeamento para evitar resfriamento
    } else {
      // MODO DIURNO: Recolher capa para absorver luz visível
      digitalWrite(RELE_CAPA_FECHAR, LOW);
      digitalWrite(RELE_CAPA_ABRIR, HIGH);
      
      if (tempAgua < 28.5) {
        digitalWrite(RELE_BOMBA, HIGH); // Liga recirculação para aquecimento no coletor
      } else {
        digitalWrite(RELE_BOMBA, LOW);  // Setpoint de temperatura atingido
      }
    }
    vTaskDelay(2000 / portTICK_PERIOD_MS);
  }
}

void setup() {
  Serial.begin(115200);
  sensors.begin();
  pinMode(RELE_BOMBA, OUTPUT);
  pinMode(RELE_CAPA_FECHAR, OUTPUT);
  pinMode(RELE_CAPA_ABRIR, OUTPUT);

  // Criação da Tarefa no Core 1 do ESP32
  xTaskCreatePinnedToCore(TaskSensorRead, "SensorTask", 4096, NULL, 1, NULL, 1);
}

void loop() {
  // Loop principal livre para rotinas de rede e telemetria Wi-Fi
  vTaskDelay(1000 / portTICK_PERIOD_MS);
}
